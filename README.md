# DecodeLabs Cyber Security Internship Tasks

My project submissions for the DecodeLabs Cyber Security internship. Both projects are written in Python, and each folder has its own README with an example run.

| Project | What it does | Folder |
| --- | --- | --- |
| Project 1: Password Strength Checker | Looks at a password, counts the character types in it, and gives it a score out of 5 with a hint. The password is hidden while you type. | [project-1-password-checker](project-1-password-checker/) |
| Project 2: Caesar Cipher | Encrypts text by shifting each letter by a key, then decrypts it back to show both results. Spaces and punctuation are kept. | [project-2-caesar-cipher](project-2-caesar-cipher/) |
