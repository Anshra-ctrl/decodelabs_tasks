# DecodeLabs Cyber Security Internship Tasks

My project submissions for the DecodeLabs Cyber Security internship. Each folder has its own README.

| Project | What it does | Folder |
| --- | --- | --- |
| Project 1: Password Strength Checker | Looks at a password, counts the character types in it, and gives it a score out of 5 with a hint. The password is hidden while you type. | [password-checker](password-checker/) |
| Project 2: Caesar Cipher | Encrypts text by shifting each letter by a key, then decrypts it back to show both results. Spaces and punctuation are kept. | [Caesar Cipher](Caesar%20Cipher/) |
| Project 3: Phishing Awareness Analysis | Analysis of a real UAE Flag Day WhatsApp scam: suspicious links, red flags, why it is unsafe, and the triage decision. | [project-3-phishing-analysis](project-3-phishing-analysis/) |
